# Retail-Fashion-Data-Analysis
Retail Fashion Data Analysis and Sales Dashboard using Microsoft Excel, Power Query, Power Pivot, and DAX.

## Project Overview
This project focuses on analyzing Retail Fashion Data using Microsoft Excel to transform raw sales data into meaningful business insights.
The project covers the complete data analysis process, including data cleaning and preparation, data transformation, data modeling, Power Pivot, DAX measures, PivotTable, data visualization, and interactive dashboard development.
The final dashboard provides an overview of sales performance, product categories, customer characteristics, profit, and product returns.

## Objectives
- Clean and standardize raw retail fashion data.
- Prepare data for analysis and visualization.
- Build relationships between different datasets.
- Create calculations and measures using Power Pivot and DAX.
- Analyze sales, returns, customer age, and profit.
- Develop an interactive sales dashboard to present business insights.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PivotTable
- PivotChart
- Cube Functions

## Data Preparation
The dataset was cleaned and prepared using Power Query.

Several data cleaning processes were performed, including:
- Standardizing gender values such as Male/male → M.
- Standardizing FEMALE/Female → F.
- Replacing invalid ??? values with Unknown.
- Removing unnecessary spaces using the Trim function.
- Creating a Day Name attribute from transaction dates.

## Data Modeling & Analysis
The project uses Power Pivot to create a Data Model and establish relationships between related tables.

Several measures and calculations were created, including:
- Total Quantity Sold
- Total Returned
- Average Age
- Profit

## What-If Analysis
A What-If Analysis was performed using Excel Data Table with sales scenarios ranging from -15% to +15%.
The initial Total Quantity Sold was 124,076 units. Under the simulated scenarios, projected quantity sold ranged from approximately 105,464 units to 142,687 units.
This analysis demonstrates how changes in sales performance can affect the total quantity of products sold.
